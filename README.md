# AGA · universo

Site interativo da marca AGA, acionado por NFC, hospedado em [agacoffee.com.br](https://agacoffee.com.br).

## estrutura

- `index.html` — página principal, universo 3D interativo com cafés e informações da marca
- `404.html` — página para endereços não encontrados
- `CNAME` — configuração do domínio custom para GitHub Pages

## deploy

Este repositório é publicado automaticamente pelo GitHub Pages na branch `main`, pasta `/`.

Para atualizar o site, substituir o `index.html` e dar commit. A publicação acontece em 1 a 2 minutos.
